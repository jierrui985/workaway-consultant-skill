# Workaway 义工换宿 Skill

通用的 Workaway 换宿项目分析与申请辅助 Skill。它将房东信息、旅行成本和用户资料结合，帮助判断是否适合申请，并生成英文申请信和中文翻译。支持任何出发国家的用户；默认费用保留原币并换算人民币，可额外展示用户偏好币种。

这是一套 Markdown 指令与模板，无需 API 密钥或额外运行服务。它不隶属于 Workaway，也不保证获得房东接待。

## 使用

1. 将整个文件夹放入支持本地 Skill 的助手所配置的技能目录，保持相对路径不变。仅复制 `SKILL.md` 会丢失模块与模板。具体加载方式以所用助手为准。
2. 在会话中先提供房东链接、截图或介绍。Skill 会根据这个项目先发一张简短的个人资料表，此时不会提前分析。
3. 回答出发地、日期、技能、语言、预算及项目特有条件后，Skill 才生成完整报告。也可以提前在 Skill 目录之外填写[用户资料模板](用户资料模板.md)，避免重复问答。
4. 完整报告以唯一十分制总分开头，例如 `综合评分：6.0/10｜谨慎考虑`。项目概况介绍县市位置，附 Google Maps 导航链接、地点图片和周边景点；景点附相关 Instagram／YouTube 内容、可核实的点赞数及日期。
5. 核对输出的待确认项，再使用申请信草稿。Skill 本身不发送消息、不订票，也不发布用户资料。

示例请求（下列是输入格式，不含真实用户资料）：

```text
请使用 workaway-consultant-skill 分析这个 Workaway 项目：
[链接、截图或完整文字介绍]

请先根据项目向我询问必要的个人资料。等我回答后，再用地点图片和简洁表格输出完整分析。
```

也可要求仅比较两个项目、更新交通费用或修改申请信；无需强制生成完整报告。

## 输出与评分

完整报告先展示总分和结论，再包含项目概况（含地理位置、地图与周边景点）、交通路线与成本、房东需求分析、用户匹配分析、申请策略、评分依据和申请信。主要信息用简洁表格展示。收到房东资料但尚未收到用户资料时，Skill 只发送针对性资料表，不提前生成报告。

- 匹配度为 0–100，按六项加权，不代表申请成功概率。
- 综合评价为十分制单一分数，保留一位小数，同时给出强烈推荐／推荐／谨慎考虑／不推荐；不输出分数范围或多个情境总分。
- 部分资料缺失时按已知维度重新归一权重，给单一暂定分，另列信息覆盖率和待确认项；未知不记零分或满分。资料不足以支持主要判断时先收集资料；硬性要求冲突优先于高分。
- 权重和计算见[匹配模块](modules/用户匹配分析.md)与[综合评价模块](modules/综合评价.md)，便于审核与修改。

## 需要的能力与限制

助手需能阅读所提供的文字；分析截图需要图像阅读能力。完整时效核实和地点图片需要网页及图片搜索能力，或由用户提供近期可靠资料。网站无法访问时可改用用户提供的介绍，不绕过登录或访问限制；无法可靠展示在线图片时使用带标题的来源链接。

实时票价、班次、汇率、旅行安全和入境规定应查询实际来源；不能查询时输出已知内容和待查项。尚未定价的必要路段不会被当成零费用。用户没有提供经历或日期时，申请信保留明确占位符并标为草稿。

地图默认导航至可核实的县市，不定位房东私宅。周边景点优先选择休息日可达的地点；Instagram／YouTube 内容默认以至少 1 万点赞为高赞筛选目标。无法核实点赞量或未找到达标内容时明确标注，不拿播放量替代点赞数、不伪造链接。筛选和降级规则见[地理分析](modules/地理分析.md)。

本版提供旅行与申请决策辅助，不包含完整签证判断、自动航班检索程序或自动投递功能。

## 隐私与开源

仓库仅保留通用规则和空白模板。已填资料、真实房东沟通、个人报告和申请信应存放在仓库之外。`.gitignore` 额外排除常见私人目录，但无法识别随意命名的敏感文件；发布前仍应检查文件与提交历史。

项目采用 [MIT License](LICENSE)。可以修改、分享和用于商业用途，并按许可证要求保留声明。本次交付是可发布的源文件包，尚未上传 GitHub。

## 维护与扩展

修改评分时保持权重合计为 100%，同步检查匹配分到综合分的换算。新增模块需从 `SKILL.md` 链接并说明读取时机；模板只存通用结构，不写真实人物资料。

未来可独立增加签证分析、航班优化、旅行预算等模块；届时定义所需输入、官方信息来源和无法查询时的行为，再接入主流程。

维护时可用以下场景检查行为：收到房东链接但无用户资料时只提问并停止；用户回答后才输出分析且开头只有一个十分制总分；评分依据不全时给单一暂定分并披露未知项；县市地图不误指同名地点或私宅；景点内容真实相关且点赞数可追溯，点赞不可见时明确说明；地点图片与实际位置及来源一致；主要信息优先用短表格；无联网时不编造票价或图片；缺最后一段费用时只给部分小计；日期不符合最短停留时限制推荐；英文与中文不产生不同承诺。
