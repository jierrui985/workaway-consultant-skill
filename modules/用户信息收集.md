# 用户信息收集

## 目的

房东资料只能描述项目，用户资料决定路线、成本、匹配度和申请策略。收到房东资料后，先根据该项目生成一张简短的资料收集表，等待用户回答后再分析。

## 提问规则

- 先从房东资料识别会影响匹配的条件，例如宠物、吸烟、体力工作、合住房、驾驶、网络或最低停留。
- 最多用 8 行收集信息；把相近问题合并，不发送冗长问卷。
- 用户已经说过的信息直接带入表格，不再询问。
- 只问与当前项目有关的敏感或个人信息。只有需要核对入境条件时才问国籍／护照签发国，不询问号码。
- 用户回答不完整时，只追问会阻止路线、评分或申请信定稿的项目。
- 发送资料表后停止本轮，不附带初步评分、推荐或申请信。

## 默认资料表

先用一句话说明为什么需要这些信息，再给表格。根据房东项目删除无关行，并加入一行项目特有条件。

| 请补充 | 你的信息 |
| --- | --- |
| 出发地 | 城市或常用机场 |
| 日期 | 最早到达、最晚离开、可停留多久 |
| 预算 | 交通预算；单程或往返；每人或总额 |
| 语言 | 实际交流水平 |
| 相关技能 | 与房东任务最相关的真实经验，最好附具体例子 |
| 个人偏好 | 希望做的工作、不想做或不能做的工作 |
| 生活条件 | 是否接受宠物、吸烟、合住房、有限网络及相应项目条件 |
| 旅行目标 | 此次最看重文化体验、地点、技能、预算或其他目标 |

如果房东有驾驶、年龄、资质、体力或特定日期等硬性要求，将相应内容放进「个人偏好／项目条件」行。需要入境核实时再加：`国籍／护照签发国（无需号码）`。

结尾只说：`按表格顺序简短回答即可；收到后我再进行完整分析。`

## 进入分析的最低信息

通常需要：出发地、旅行日期或可用范围、停留长度、至少一项相关技能或明确无经验、语言水平，以及对项目显著生活条件的接受度。预算缺失时可以分析，但交通成本只能作为金额参考，不能判断是否符合预算。
